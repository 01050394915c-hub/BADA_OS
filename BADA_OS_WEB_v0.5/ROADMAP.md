# BADA OS v1.0 개발 로드맵

아래 순서대로 진행하면, 기존 프로젝트를 크게 망가뜨리지 않고 v1.0으로 점진적으로 확장할 수 있습니다.

## 1단계: 현재 Amazon 기능 정상 수집 및 화면 표시
- [ ] Amazon 수집이 실제로 실행되는지 확인한다.
- [ ] 수집된 상품명이 정상적으로 후보 카드에 보여지는지 확인한다.
- [ ] 수집 실패 시에도 빈 목록과 에러 로그가 남는지 확인한다.

수정할 파일
- backend/amazon.py
- server.py
- index.html

완료 기준
- Amazon 수집 결과가 있으면 후보 카드에 반영된다.
- 실패해도 프로그램이 멈추지 않는다.

테스트 방법
- 서버 실행 후 "40개 자동 소싱 시작" 버튼 클릭
- 브라우저에서 후보 카드와 scan_info 확인

## 2단계: 설정 화면과 소스별 ON/OFF
- [ ] settings에 Google Trends, Naver, Amazon 등 소스별 ON/OFF 값을 추가한다.
- [ ] 사용자가 체크박스로 소스를 켜고 끌 수 있게 만든다.
- [ ] ON/OFF 상태가 data.json에 저장되고 다음 실행 때 유지되도록 한다.

수정할 파일
- index.html
- server.py
- data.json

완료 기준
- 설정 화면에서 각 소스를 켜고 끌 수 있다.
- 저장된 설정이 다음 실행 때 반영된다.

테스트 방법
- 설정 화면에서 체크박스 변경
- 새로고침 후 값이 유지되는지 확인

## 3단계: TikTok Shop 연결
- [ ] TikTok Shop 수집 모듈을 만든다.
- [ ] 수집 결과를 기존 trend 리스트에 합친다.
- [ ] 실패 시에도 오류만 기록하고 계속 진행한다.

수정할 파일
- backend/tiktok_shop.py (신규)
- server.py

완료 기준
- TikTok Shop 수집 결과가 있으면 후보 생성에 반영된다.

테스트 방법
- 스캔 실행 후 scan_info.source_counts에 tiktok 항목이 보이는지 확인

## 4단계: 샤오홍슈 연결
- [ ] 샤오홍슈 수집용 모듈을 만든다.
- [ ] 키워드와 제품 정보 형태로 정리한다.
- [ ] 후보 생성 단계에서 참고 신호로 반영한다.

수정할 파일
- backend/xiaohongshu.py (신규)
- backend/scoring.py

완료 기준
- 샤오홍슈 데이터가 추천 이유나 신호에 반영된다.

테스트 방법
- 샤오홍슈 수집이 성공/실패해도 스캔이 정상 종료되는지 확인

## 5단계: 쿠팡 경쟁도 분석
- [ ] 쿠팡 검색 결과와 리뷰 수, 가격대, 판매자 수를 수집하는 모듈을 만든다.
- [ ] 경쟁이 심한 상품은 점수를 낮추거나 리스크를 추가한다.

수정할 파일
- backend/coupang.py (신규)
- backend/scoring.py

완료 기준
- 경쟁도 정보가 후보 카드의 risk나 reason에 반영된다.

테스트 방법
- 특정 키워드로 실행해 점수 변화가 있는지 확인

## 6단계: KC 인증과 상표권 안내
- [ ] KC 인증 필요 여부를 판단하는 모듈을 만든다.
- [ ] 상표권/디자인권 리스크 안내를 붙인다.
- [ ] 사용자에게 안전하게 확인해야 할 항목으로 표시한다.

수정할 파일
- backend/compliance.py (신규)
- backend/scoring.py
- index.html

완료 기준
- KC 인증 필요 상품에 안내 메시지가 표시된다.
- 상표권 리스크가 카드에 반영된다.

테스트 방법
- 화면에서 카드의 risk 또는 상세 메시지 확인

## 7단계: AI 최종 점수와 오늘의 TOP10
- [ ] 여러 소스의 점수를 종합하는 AI/규칙 기반 점수 계산 로직을 만든다.
- [ ] TOP10 후보를 따로 뽑아 메인 화면에 강조한다.
- [ ] 추천 이유를 더 자연스럽게 정리한다.

수정할 파일
- backend/scoring.py
- index.html
- server.py

완료 기준
- 화면에서 TOP10 후보가 별도로 보인다.
- 점수와 이유가 더 정교하게 조합된다.

테스트 방법
- 수집 후 상위 10개 후보가 TOP10 영역에 표시되는지 확인

## 8단계: 전체 테스트와 v1.0 배포
- [ ] 전체 기능을 함께 실행해 보고 오류를 수정한다.
- [ ] 설정, 수집, 저장, 화면 표시가 모두 정상 동작하는지 확인한다.
- [ ] README와 문서를 정리한다.
- [ ] 배포용 실행 방법을 정리한다.

수정할 파일
- README.txt
- ARCHITECTURE.md
- ROADMAP.md

완료 기준
- 주요 시나리오를 모두 테스트해 문제 없이 실행된다.
- 사용자에게 배포 방법을 설명할 수 있다.

테스트 방법
- 서버를 실행하고 전체 스캔, 설정 변경, 데이터 저장, 화면 표시를 확인한다.
